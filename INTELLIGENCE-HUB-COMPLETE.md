## 🔥 Key Features

### **1. Unified Findings Feed**
- All findings from ALL detection methods in ONE place
- Tabbed views: All / Anomalies / Violations / Predictions / Correlations
- Search across all findings
- Click any finding for full details

### **2. Automatic Cross-Correlation** (NEW!)
```typescript
// System automatically detects when multiple issues affect same facility:
{
  title: "Multiple Issues Detected",
  facility: "Switch Inc - Grand Rapids",
  issues: [
    "Statistical Anomaly (0.89 score)",
    "Intent Violation (97.4% job shortfall)",
    "Predicted degradation (45 days)"
  ],
  rootCause: "Systemic non-compliance",
  relatedFindings: [anomaly-123, intent-456, predict-789]
}
```

### **3. Root Cause Analysis** (NEW!)
```typescript
// AI-powered causality detection:
{
  rootCause: "Operator failed to meet subsidy agreement terms",
  contributingFactors: [
    "Insufficient hiring",
    "Inadequate compliance tracking",
    "Lack of enforcement"
  ]
}
```

### **4. Scenario Builder** (Enhanced Pattern Lab)
```typescript
// Create scenarios that run ALL analysis methods:
{
  name: "Michigan Deep Dive",
  filters: { states: ["MI"] },
  analysis: {
    detectAnomalies: true,    // Statistical
    validateIntent: true,      // Assurance
    forecastTrends: true,      // Predictions
    visualizeGraph: true,      // Graph
  }
}
// Returns comprehensive findings across all methods
```

### **5. Intelligent Graph View** (Embedded Compliance Flow)
```typescript
// Click "Graph View" to see:
{
  nodes: [...],  // Operators + States
  edges: [...],  // Relationships
  intelligence: {
    criticalNodes: ["Switch Inc"],  // Auto-highlighted red
    warnings: ["Google Cloud"],     // Yellow borders
    clusters: [                     // Pattern grouping
      { name: "Low Compliance", nodes: [...] }
    ]
  }
}
```

### **6. Finding Detail Modal**
Click any finding to see:
- Full evidence (expected vs. actual)
- Root cause analysis
- Suggested actions (auto-generated)
- Related findings (cross-correlation)
- Confidence scores
- Detection method used

## 🎬 How to Use

### **Step 1: Open Intelligence Tab**
Click **"Intelligence"** in the main navigation.

### **Step 2: Review Dashboard**
See 6 metric cards at top:
- Total Findings
- Critical (red)
- Anomalies (orange)
- Violations (yellow)
- Predictions (blue)
- Correlations (purple)

### **Step 3: Filter Findings**
Click tabs to filter:
- **All Findings** - Everything
- **Anomalies** - Statistical outliers
- **Violations** - Intent failures
- **Predictions** - Future warnings
- **Correlations** - Multi-issue facilities

### **Step 4: Search**
Type in search box to find specific facilities or operators.

### **Step 5: Click Findings**
Click any finding card to see:
- Full details
- Evidence
- Root cause
- Suggested actions
- Related findings

### **Step 6: Build Scenarios** (Optional)
1. Click "Scenario Builder"
2. Name your scenario (e.g., "Michigan Deep Dive")
3. Select analysis methods (Anomalies, Intent, Predictions, Graph)
4. Click "Run Scenario"
5. View results in findings feed

### **Step 7: View Graph** (Optional)
1. Click "Graph View"
2. See interactive Cytoscape visualization
3. Critical nodes highlighted in red
4. Warning nodes in yellow
5. Healthy nodes in green
