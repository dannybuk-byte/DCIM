## ⌨️ Keyboard Shortcuts

Quick reference for hotkeys:

### Global:
- `?` → Open Help
- `F` → Toggle fullscreen
- `Esc` → Exit fullscreen / Close modal

### Navigation:
- `1` → Switch to OMNI view
- `2` → Switch to DEEP view
- `3` → Switch to HUD view
- `4` → Switch to MAP view

### Search:
- `Enter` → Execute search
- `Esc` → Close suggestions

### Mouse:
- Hover top → Expand top bar
- Hover left → Show timeline
- Hover right → Show alerts

## 🎯 Recommended Paths

### For Brand New Users:

1. **Press `?`** to open Help
2. **Click "Quick Start Guide"**
3. **Read all 4 steps** to understand the basics
4. **Scroll down** to read the "Complete Investigation Walkthrough"
5. **Close Help** and try the walkthrough yourself!
6. **Come back** to Help when you get stuck (press `?` anytime)

### For Users Who Want to Search:

1. **Press `?`** to open Help
2. **Click "FAQs & Answers"**
3. **Click "Search & Filters" category button** at top
4. **Read**: "How do I search for facilities?"
5. **Read**: "What are Investigation Templates?"
6. **Try both methods** in the dashboard

### For Users Having Issues:

1. **Press `?`** to open Help
2. **Click "FAQs & Answers"**
3. **Click "Troubleshooting" category button** at top
4. **Find your issue**:
   - Natural Language Search isn't working
   - The dashboard feels slow
   - I can't see all the data
   - Smart Panels keep appearing
5. **Follow the diagnostic questions** to solve the issue

### For Advanced Users:

1. **Press `?`** to open Help
2. **Click "Keyboard Shortcuts"**
3. **Memorize hotkeys** for faster navigation
4. **Click "FAQs & Answers"** → **"Advanced" category**
5. **Learn about**:
   - Customization options
   - Offline mode
   - Compliance thresholds
