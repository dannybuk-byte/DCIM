# DART v0.9 — Evidence requirements

No criterion passes from narrative alone.

## Deterministic checks

Require exact command, real exit code, input/output hashes where applicable, and an artifact pointer.

## Runtime observations

Require exact HEAD/worktree, environment, command, timestamp, response or screen capture, and real exit code. A dated observation is not a permanent liveness claim.

## Human review

Require reviewer role, date, exact packet/build, question asked, what was understood, confusion, requested next record/feature, and disposition.

## Principal rulings

Require an exact quoted line and scope. Agent completion, checklist status, or test success cannot substitute.

## External dependencies

Remain `UNDERIVED`, `ABSENT`, or `UNRESOLVED` until official documentation or exact response bytes support them.

## Mandatory completion packet

- starting branch, worktree, HEAD, and status;
- loaded spec and acceptance hashes;
- exact input manifest;
- files written;
- diff/stat;
- tests and exit codes;
- serialized API packet;
- UI capture and test;
- source/raw/provenance hashes;
- unresolved conditions;
- independent verifier report;
- expert/user review record;
- final Git status;
- explicit statement that no push, deploy, send, publication, or source-admission act occurred unless separately authorized.
