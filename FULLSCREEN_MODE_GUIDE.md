# 🎯 Fullscreen Mode - User Guide

## ✅ FULLSCREEN EXPANSION NOW AVAILABLE!

Every view can now expand to cover the entire screen with one click!

---

## 🎮 How to Use Fullscreen

### Method 1: Click the Button
Look for the **cyan expand icon** (⛶) in the **top-right corner** of the center view area.

- **Click once** → Fullscreen mode (hides all panels)
- **Click again** → Normal mode (shows panels)

### Method 2: Keyboard Shortcuts
- Press **`F`** → Toggle fullscreen on/off
- Press **`Esc`** → Exit fullscreen (when in fullscreen)

---

## 📺 What Happens in Fullscreen Mode

### Hidden Elements:
- ✕ Top bar (DCIM OMNISCIENT header + mode buttons + stats)
- ✕ Left timeline (vertical year markers)
- ✕ Right activity feed (live alerts panel)
- ✕ Bottom ticker (scrolling facility names)

### Visible Elements:
- ✓ Full view takes entire screen
- ✓ Expand/collapse button (top-right)
- ✓ "FULLSCREEN MODE" indicator (top-left)
- ✓ Current view name (top-center)
- ✓ All view content (100% screen space)

## 💡 When to Use Fullscreen

### Best For:

1. **Presentations**
   - Remove distractions
   - Focus audience attention
   - Maximum visual impact

2. **Deep Analysis**
   - More space for data
   - See more facilities at once
   - Better overview

3. **Network View**
   - See all operator clusters
   - More room for connections
   - Better spatial layout

4. **Map View**
   - Larger geographic area
   - More detailed state markers
   - Better spatial awareness

5. **Kanban Board**
   - More vertical space for columns
   - See more cards per column
   - Better workflow view

### Less Useful For:

- **Monitoring** (need activity feed for alerts)
- **Context switching** (need mode buttons visible)
- **Multi-tasking** (need stats always visible)

## 🎬 Workflow Examples

### Example 1: Deep-Dive Analysis
1. Start in normal mode (see stats + alerts)
2. Choose your view (e.g., NETWORK)
3. Click expand button → Fullscreen
4. Analyze with maximum space
5. Press `Esc` when done

### Example 2: Presentation Mode
1. Connect to projector
2. Navigate to desired view
3. Press `F` for instant fullscreen
4. Present with zero clutter
5. Press `F` again to show controls

### Example 3: Quick Check
1. Working in normal mode
2. Need to see more of map
3. Click expand for 10 seconds
4. Click expand again to restore
5. Continue monitoring in normal mode
