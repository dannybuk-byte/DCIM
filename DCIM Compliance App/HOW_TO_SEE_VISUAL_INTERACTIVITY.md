## 🎨 Visual Feedback Guide

### **Color Meanings**:
- **Cyan (#00d2d3)**: Primary interactive state (hover)
- **Green (#2ed573)**: Activated state (selected category, section hover)
- **White**: Text emphasis (hover over descriptions)
- **Gray → Cyan/White**: De-emphasized → Emphasized

### **Animation Meanings**:
- **Scale Up (Grow)**: "This is clickable/hoverable"
- **Glow/Shadow**: "This is important/active"
- **Slide Right**: "This is a link or action"
- **Rotate**: "This state has changed" (arrow direction)
- **Gradient Appear**: "This element is now in focus"

### **Timing**:
- **Fast (300ms)**: Colors, small movements (responsive feel)
- **Medium (500ms)**: Rotations, expansions (smooth feel)
- **Continuous (pulse)**: Important static elements (attention)
